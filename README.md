# SPIRIT/CTRL Launcher

Официальные установщики и обновления SPIRIT/CTRL Launcher для Windows x64.

## Скачать

[Последний стабильный выпуск](https://github.com/settlerbro-hue/spirit-ctrl-launcher-releases/releases/latest)

Установите файл с окончанием `-setup.exe` один раз. Следующие обновления проверяются внутри лаунчера; скачивание и перезапуск выполняются по команде пользователя вне эфира.

Турниры, игроки, фотографии и настройки хранятся отдельно от файлов приложения. Установка поверх Portable использует тот же профиль Windows.

## Версия 1.2.19 · Dota HUD 2.8.22 · Static HUD 2.1.0

- Перенос базы Dota и CS2 через ZIP. Архив сохраняет турниры, команды, составы, фотографии с кадрированием, партнёров и оформление.
- Перед импортом доступны предпросмотр, добавление и обновление или замена. Для отката создаётся резервная копия. Импорт старых XLSX доступен в разделе совместимости.
- Уменьшен дистрибутив. В упаковке используется активный комплект Minify, оставлены русская и английская локализации Electron, оптимизированы 53 видео героев с сохранением прозрачности.
- Обновлён ESL. В драфте изменены карточки героев, составы и нижняя панель. На брендированных экранах используется логотип выбранного турнира.
- В игровом ESL HUD фото обрезается по форме плашки. В статистике обновлены столбцы игроков и заголовки команд, в лайв-скорборде фото показывается целиком.

Обновлённый ESL.zip приложен к выпуску.

- В CS2 обновлена «Арена», встроен ECLIPSE и добавлен импорт совместимого архива Pavaga CS2 2026. Исправлены карты серии, киллфид, радар, MVP и отдельные таймеры взрыва/обезвреживания C4.

## Проверка файла

В каждом выпуске доступны `SHA256SUMS.txt`, установщик и служебные файлы автообновления `latest.yml` и `blockmap`.

Этот репозиторий содержит только выпуски и информацию для обновления. Исходный код разрабатывается в отдельном репозитории.
