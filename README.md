# SPIRIT/CTRL Launcher

Официальные установщики и обновления SPIRIT/CTRL Launcher для Windows x64.

## Скачать

[Последний стабильный выпуск](https://github.com/settlerbro-hue/spirit-ctrl-launcher-releases/releases/latest)

Установите версию с окончанием `-setup.exe` один раз. Следующие обновления проверяются внутри лаунчера; скачивание и перезапуск выполняются по команде пользователя вне эфира.

Пользовательские турниры, игроки, фотографии и настройки хранятся отдельно от файлов приложения. Установка поверх Portable использует тот же профиль Windows.

## Версия 1.2.7 · HUD 2.8.13

- В режиссёре появился общий выбор дизайнов с предпросмотром: шесть комплектов, независимый выбор каждого экрана и перенос полных макетов через ZIP.
- Добавлены три полноэкранных расположения драфта без свободного места под камеру.
- HUD можно открыть отдельным полноэкранным окном без рамок поверх остальных окон для захвата в OBS.
- Добавлены подключение к API сайта, предпросмотр изменений и синхронизация турниров, составов и фотографий с сохранением ручных настроек.
- У игрока доступны три фотографии: с сайта, локальная и дополнительная; активное фото выбирается отдельно и сохраняется при синхронизации.
- Формы команды и игрока открываются по кнопке; карточки команд показывают составы, быстрый импорт фотографий убран из вкладки игроков.
- Переработаны основные настройки, резервные копии, Excel и обновление с версиями всех компонентов; подключение трансляции перенесено к режиссёру.
- Подробные состояния перенесены в диагностику, в матче добавлены компактные индикаторы; нагрузку лаунчера и системы можно скрыть.
- Курьеры с предметами и подтверждённые таймеры отображаются справа независимо от выбранного героя; лайв-графики удалены из интерфейса.
- Исправлены закрытие редактора турнира после сохранения и экспорт PNG с последними настройками оформления.

## Проверка файла

В каждом выпуске доступны SHA256SUMS.txt, установщик и служебные файлы обновления latest.yml и blockmap.

Этот репозиторий содержит только выпуски и информацию для обновления. Исходный код разрабатывается отдельно.
