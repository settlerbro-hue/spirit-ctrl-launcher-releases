# SPIRIT/CTRL Launcher

Официальные установщики и обновления SPIRIT/CTRL Launcher для Windows x64.

## Скачать

[Последний стабильный выпуск](https://github.com/settlerbro-hue/spirit-ctrl-launcher-releases/releases/latest)

Установите файл с окончанием `-setup.exe` один раз. Следующие обновления проверяются внутри лаунчера; скачивание и перезапуск выполняются по команде пользователя вне эфира.

Турниры, игроки, фотографии и настройки хранятся отдельно от файлов приложения. Установка поверх Portable использует тот же профиль Windows.

- Комплекты ECLIPSE и ESL доступны отдельными ZIP для импорта через «Режиссёр → Комплекты оформления». [Архивы выпуска](https://github.com/settlerbro-hue/spirit-ctrl-launcher-releases/releases/tag/v1.2.15)

## Версия 1.2.11 · Dota HUD 2.8.16 · CS2 HUD 0.4.0

- Обновлённый стартовый экран, обязательный вход через сайт SPIRIT/CTRL, восстановление сессии и закрытие доступа после выхода.
- Увеличенный бар курьеров: крупные предметы, портреты и таймеры, яркие и толстые линии команд.
- Контроль всех типов рун с отдельной статистикой команд, баунти и мудростью по центру, обработкой Bottle и повторных событий.
- Увеличенные базовые панели статистики и выкупов; исправлено переключение портретов в сравнении игроков.
- Общий портрет во всех Dota-скорбордах: фото поверх обесцвеченного героя, цветной герой при отсутствии фото, сохранение медиа при экспорте PNG.
- Обновлённые лайв- и финальный скорборды, анонс, счёт серии и пять панелей статистики комплекта «Герои».
- Расширенные данные кастомных макетов: составы, пики и баны, предметы, улучшения, логотипы партнёров.
- CS2 HUD 0.4.0: каталог макетов с предпросмотром, обновлённые игровой HUD и статистика, финальный экран, пауза, MVP с фото, нижний HUD и оформление повтора для OBS.
- MVP раунда CS2 определяется автоматически по подтверждённому приросту игрового счётчика; карточка выводится поверх основного HUD. При неполных данных остаётся ручной выбор.
- Исправлена привязка командных цветов к новым экранам CS2.

Static HUD 2.0.0 остаётся необязательным для базового комплекта. Полная система серверных платных лицензий пока находится в разработке.

## Проверка файла

В каждом выпуске доступны `SHA256SUMS.txt`, установщик и служебные файлы автообновления `latest.yml` и `blockmap`.

Этот репозиторий содержит только выпуски и информацию для обновления. Исходный код разрабатывается в отдельном репозитории.
