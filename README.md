# SPIRIT/CTRL Launcher

Официальные установщики и обновления SPIRIT/CTRL Launcher для Windows x64.

## Скачать

[Последний стабильный выпуск](https://github.com/settlerbro-hue/spirit-ctrl-launcher-releases/releases/latest)

Установите файл с окончанием `-setup.exe` один раз. Следующие обновления проверяются внутри лаунчера; скачивание и перезапуск выполняются по команде пользователя вне эфира.

Турниры, игроки, фотографии и настройки хранятся отдельно от файлов приложения. Установка поверх Portable использует тот же профиль Windows.

## Версия 1.2.10 · HUD 2.8.15

- Полный комплект «Базовый» со всеми 14 экранами стал оформлением по умолчанию. Работает без Static HUD; сохранённые пользовательские комплекты остаются на месте.
- Базовый драфт переключается между вариантами «С вебкой / Без вебки». Обновлены игровые плашки, статистика, скорборды, сравнение, пауза, экономика, руны и Roshan.
- Таймер драфта плавно отсчитывает время между пакетами, учитывает паузу и резервное время. Обновлена обработка переключения выбранного игрока.
- Резервная копия создаётся и проверяется в фоне с окном загрузки и этапами работы. После сохранения показывается путь к ZIP.
- Исправлены размещение длинных значений GPM/XPM в MVP макета «Герои» и переключение финального скорборда в базовом пакете.
- В профиле показываются никнейм и купленный пакет. Настройки подключения к сайту находятся в профиле; доступ к CS2 проверяется по разрешению сайта.
- Встроен Static HUD 2.0.0. Для комплекта «Базовый» устанавливать его не требуется.

## Проверка файла

В каждом выпуске доступны `SHA256SUMS.txt`, установщик и служебные файлы автообновления `latest.yml` и `blockmap`.

Этот репозиторий содержит только выпуски и информацию для обновления. Исходный код разрабатывается в отдельном репозитории.
